# Evidence Templates

These files are blank forms. They are not proof of execution.

1. `baseline_evidence.md` — record environment and baseline identifiers.
2. `smoke_test_evidence.md` — record the command, timestamp, output, and exit status.
3. `release_traceability.md` — connect a release label to actual commits and test evidence.

For authentic evidence, run the commands on your machine and capture the resulting output. Never replace actual results with expected or illustrative output.
